# Private beta FAQ (draft)

## What does AI Growth OS do?

Connect a website, scan for SEO/AI-visibility issues, propose safe fixes, and — with your approval — deploy to WordPress, verify live HTML, and roll back if needed.

## Is it safe?

Every deploy creates a backup. Verification checks live HTML. Failed verification triggers automatic rollback. You approve before anything is written.

## What can it change today?

Meta title, meta description, FAQ schema JSON-LD, and **canonical URLs**.

**Deploy by connect type:** WordPress (live plugin write), GitHub (opens PR), ZIP (fix pack), Live URL (apply guide + HTML recheck — no remote write).

The Site scan page now shows a **Top fixes** list in plain language (why it matters + how to fix), including issues that are manual-only.

## Do I need OpenAI?

No. Proposals work with deterministic rules. An API key only polishes meta copy.
